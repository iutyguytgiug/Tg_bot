# 🎬 Telegram TikTok Downloader Bot (Python 3.14)

Современный и быстрый Telegram-бот для скачивания видео, фото-слайдшоу и аудиодорожек из TikTok **без водяного знака**, оптимизированный для работы под **Python 3.14**.

---

## 🚀 Основные возможности

- 💧 **Скачивание без водяного знака**: Видео сохраняются в оригинальном HD-качестве без логотипа TikTok.
- ⚡ **Двухъядерный механизм (Dual-Engine Failover)**:
  - **Движок 1 (Tikmate + curl_cffi)**: Молниеносная загрузка и прямое получение MP4 без необходимости в FFmpeg.
  - **Движок 2 (yt-dlp)**: Надежный встроенный резервный обработчик, извлекающий чистый поток `format_id!=watermarked`.
- 🎵 **Скачивание аудио (MP3)**: Возможность скачать звук/трек из видео отдельным аудиофайлом по кнопке.
- 📸 **Поддержка фото-слайдшоу (альбомов)**: Корректно скачивает и отправляет публикации-слайдшоу медиагруппой.
- 🔗 **Поддержка всех типов ссылок**:
  - `https://www.tiktok.com/@user/video/...`
  - `https://vm.tiktok.com/...` (мобильные короткие ссылки)
  - `https://vt.tiktok.com/...`
  - `https://m.tiktok.com/...`
- 🧹 **Автоматическая очистка**: Временные медиафайлы сразу удаляются с диска после отправки в Telegram.
- 🛡️ **Обход защиты Cloudflare**: Использование `curl_cffi` с эмуляцией TLS-отпечатков браузера Chrome.

## 🛠️ Быстрый старт

### 1. Получите токен бота в Telegram
1. Откройте Telegram и найдите бота [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`.
3. Введите название бота и юзернейм (должен заканчиваться на `bot`, например `MyCoolTikTokDownloaderBot`).
4. Скопируйте полученный **HTTP API Token** (вида `7123456789:AAH...`).

### 2. Настройте файл `.env`
Откройте файл [`.env`](.env) в любом текстовом редакторе (Блокнот, VS Code) и вставьте ваш токен:
```env
BOT_TOKEN=ВАШ_ТОКЕН_ОТ_BOTFATHER
```

### 3. Запуск бота

#### Способ 1: В один клик (Windows)
Просто запустите двойным щелчком файл **`run.bat`**.

#### Способ 2: Через командную строку (PowerShell / CMD)
```powershell
# Установка зависимостей (при первом запуске)
python -m pip install -r requirements.txt

# Запуск бота
python bot.py
```

## ❓ Часто задаваемые вопросы

**В: Нужен ли FFmpeg для работы бота?**  
О: Нет! Загрузчик настроен так, что скачивает уже готовые MP4-потоки со встроенным звуком без необходимости локального перекодирования.

**В: Что делать, если видео не скачивается?**  
О: Видео может быть:
- Удалено автором
- Закрыто настройками приватности (только для друзей)
- Заблокировано в данном регионе

**В: Есть ли ограничения по размеру файлов?**  
О: Telegram Bot API имеет ограничение на отправку файлов до 50 МБ. Бот автоматически проверяет размер файла перед отправкой.
